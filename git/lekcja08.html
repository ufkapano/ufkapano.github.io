WPROWADZENIE

GitHub udostępnił możliwość tworzenia stron internetowych. Można używać programu Jekyll (a popular static site generator), oprócz zwykłych stron HTML. Jekyll pozwala używać Markdown zamiast HTML.

There are three types of GitHub Pages sites: project, user, and organization. GitHub Pages sites created after June 15, 2016 and using github.io domains are served over HTTPS. 

1. Create a repository username.github.io [Public, bez README]

2. Clone the repository:
git clone https://github.com/username/username.github.io
# powstaje katalog username.github.io

3. Enter the project folder and add files:
README.md, LICENSE, .gitignore, index.html

4. Add, commit, and push your changes:
git add --all
git commit -m "Initial commit"
git push -u origin master

5. Fire up a browser and go to https://username.github.io [działa!].

Usage limits [2026-10-23]:
(1) You can only create one user or organization site for each account on GitHub.
(2) GitHub Pages source repositories have a recommended limit of 1GB.
(3) Published GitHub Pages sites may be no larger than 1 GB.
(4) GitHub Pages sites have a soft bandwidth limit of 100GB per month.
(5) GitHub Pages sites have a soft limit of 10 builds per hour.
